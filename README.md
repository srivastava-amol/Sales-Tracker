# ☕ Local Coffee Shop Daily Sales Tracker

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a local coffee shop's daily sales dataset using Python[cite: 2]. By leveraging robust data visualization tools, it transforms raw, messy data into coherent, easy-to-understand trends[cite: 1, 2]. This analytical approach empowers small businesses to comprehend their day-to-day operations and make informed, strategic choices aligned with modern data standards[cite: 1, 2].

## 🎯 Objectives
* **Data Cleaning:** To preprocess the dataset by removing missing values and formatting data structures (like datetime conversions) to ensure it is primed for accurate analysis[cite: 1, 2, 3].
* **Descriptive Statistics:** To compute core metrics such as total daily sales, averages, and the highest-selling items to effectively summarize business performance[cite: 1, 2].
* **Visual Insights:** To graphically represent sales trends and popular item categories using intuitive bar charts, line graphs, and boxplots[cite: 1, 2, 3].
* **Operational Efficiency:** To use an automated Python script that eliminates the need for manual calculations, thereby preventing human errors and saving time[cite: 1, 2].

## 💻 Technology Stack
* **Programming Language:** Python[cite: 1, 2]
* **Primary Libraries:** Pandas, NumPy[cite: 1, 2, 3]
* **Visualization Libraries:** Matplotlib, Seaborn[cite: 1, 2, 3]
* **Operating Environment:** Google Colab[cite: 1, 2, 3]

## 📊 Key Visualizations
* **Daily Total Sales Trend:** A line chart illustrating the day-to-day total sales revenue and highlighting peak sales days[cite: 2, 3].
* **Total Sales by Coffee Type:** A bar chart displaying the total revenue generated by each coffee category to identify the most profitable items[cite: 2, 3].
* **Sales Distribution by Coffee Type:** A boxplot representing the distribution and variance of sales across different coffee types[cite: 2, 3].

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Ensure the dataset files (`index_1.csv` and `index_2.csv`) are located in the same directory as the script[cite: 3].
3. Install the required dependencies by running: 
   `pip install pandas numpy matplotlib seaborn`
4. Execute the Jupyter Notebook or Python script to clean the data and generate the visual insights.
